# 쿠폰 적용 주문 정책

이 문서는 BDD Gap Analyzer 학습을 위해 작성한 가상 제품 명세입니다. 실제 운영 서비스의 정책을 나타내지 않습니다.

문서 버전: sample-order-policy-v1
대상 기능: POST /orders 주문 요청

## ORDER-001: 쿠폰 없는 주문

- 구매 가능한 상품과 결제 수단을 가진 사용자는 쿠폰 없이 주문할 수 있습니다.
- 주문 성공 시 HTTP 201을 반환하고 주문과 결제를 생성합니다.
- 결제 금액은 상품 주문 금액과 같습니다.

## ORDER-002: 유효한 쿠폰을 적용한 주문

- 주문 요청 시점에 사용 가능한 쿠폰이면 할인 금액을 적용합니다.
- 주문 성공 시 HTTP 201을 반환하고 주문과 결제를 생성합니다.
- 결제 금액은 상품 주문 금액에서 쿠폰 할인 금액을 뺀 금액입니다.
- 예: 상품 금액 10,000원에 2,000원 할인 쿠폰을 적용하면 8,000원을 결제합니다.

## 아직 결정되지 않은 정책

만료된 쿠폰이 포함된 주문의 처리 정책은 아직 결정되지 않았습니다.
주문을 거절할지 쿠폰을 제외하고 진행할지, 응답 상태 코드와 오류 코드,
사용자에게 표시할 안내 및 주문·결제의 생성 여부는 기획자와 개발자가 확인해야 합니다.

## 명세 범위

쿠폰 중복 사용, 결제 재시도, 동시 주문에 대한 정책은 이 샘플에서 정의하지 않습니다.
